Connecting RTSP cameras (read this)

Browsers cannot play rtsp:// directly, and cannot read a camera’s pixels unless the camera/gateway allows it (CORS). Most school CCTV (Hikvision, Dahua, CP Plus, etc.) speaks RTSP, so the simplest fix is a free gateway such as go2rtc running on any PC on the same network. It turns RTSP into browser-friendly MJPEG / HLS / JPEG with CORS enabled.

Example go2rtc.yaml 
api:
  listen: ":1984"
  origin: "*"          # allow this page to read frames (CORS)

streams:
  gate1: rtsp://admin:PASSWORD@192.168.1.64:554/Streaming/Channels/102
  hall2: rtsp://admin:PASSWORD@192.168.1.65:554/cam/realmonitor?channel=1&subtype=1
Then use these URLs in this app (replace SERVER with the gateway PC’s IP):
  • MJPEG: http://SERVER:1984/api/stream.mjpeg?src=gate1
  • Snapshot: http://SERVER:1984/api/frame.jpeg?src=gate1
  • HLS: http://SERVER:1984/api/stream.m3u8?src=gate1
RTSP paths differ by brand/model — check your camera manual. Verify the URL formats in go2rtc’s documentation for your version.
  • Use the sub-stream (about 640×360 to 1280×720). Full-HD/4K main streams are slow to process in a browser.
  • Mixed content: if this page is opened from an https:// site, the browser blocks http:// camera URLs. Open this file from the school PC instead (e.g. python -m http.server 8080 then http://localhost:8080/face-attendance-system.html).
  • Camera placement: at an entrance, at about eye level, 1–3 m from faces, with even lighting and no strong backlight. Wide CCTV views of a far crowd won’t be accurate.
  • Use Test first. It reports whether the browser is allowed to read pixels (CORS). If it says “blocked”, face detection cannot work on that source.

Google Sheets sync (optional)
When set, each attendance mark and new student is also sent to your Google Sheet.
Google Apps Script code 
function doPost(e) {
  var d = JSON.parse(e.postData.contents);
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  function sheet(n, h) {
    var s = ss.getSheetByName(n) || ss.insertSheet(n);
    if (s.getLastRow() === 0) s.appendRow(h);
    return s;
  }
  if (d.action === 'attendance') {
    var s = sheet('Attendance', ['Date','Time','Roll','Name','Class','Status','Camera']);
    d.records.forEach(function (r) {
      s.appendRow([r.date, r.time, r.roll, r.name, r.cls, r.status, r.cam]);
    });
  } else if (d.action === 'student') {
    var s2 = sheet('Students', ['Roll','Name','Class','Section']);
    s2.appendRow([d.roll, d.name, d.cls, d.section]);
  }
  return ContentService.createTextOutput('OK');
}
Backup & data
Data (students, cameras, records) is stored in this browser’s localStorage on this PC. Take regular backups. Camera URLs may contain passwords, so keep backup files private.
